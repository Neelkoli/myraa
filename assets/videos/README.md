# Character videos

Drop your 3 videos of the same AI girl here with these **exact** names:

| File                        | State     | Used when                                   |
|-----------------------------|-----------|---------------------------------------------|
| `JUST WAITNG.mp4`           | IDLE      | waiting / app open (loops)                  |
| `ANIMA GIRL THINKING.mp4`   | THINKING  | user message received / Gemini generating   |
| `ANIMA GIRL TAKING.mp4`     | TALKING   | TTS / voice playback active                 |

Until the files are present, Myraa shows her built-in animated fallback avatar.
You can also upload the videos from **Settings → Character** instead of copying files here.
